## 基本结构

标准的头文件应包含以下部分：

```c
#ifndef HEADER_NAME_H  // 头文件保护
#define HEADER_NAME_H

// 预处理指令
#include <standard_header>
#include "custom_header"

// 常量宏定义
#define MACRO_NAME value

// 函数宏定义
#define MACRO_FUNCTION(x) ((x) * 2)

// 类型定义
typedef struct { ... } StructName;

// 函数声明
void function_name(void);

#endif  // HEADER_NAME_H
```

## 防止多重包含

### 方法1：使用 #ifndef 和 #define（推荐）

```c
#ifndef MY_HEADER_H
#define MY_HEADER_H

// 头文件内容

#endif // MY_HEADER_H
```

**命名规则：** `文件名_H` （全大写，将点和特殊字符替换为下划线）

| 文件名 | 宏定义名 |
|--------|---------|
| utils.h | UTILS_H |
| my_config.h | MY_CONFIG_H |
| data_types.h | DATA_TYPES_H |

### 方法2：使用 #pragma once（现代编译器支持）

```c
#pragma once

// 头文件内容
```

## 宏定义命名规范

### 基本规则

| 类型 | 规范 | 示例 |
|------|------|------|
| **常量宏** | 全大写，单词用下划线分隔 | `MAX_SIZE`, `PI_VALUE` |
| **类型相关** | 全大写后加_T | `INT32_T`, `SIZE_T` |
| **标志/选项** | ENABLE/DISABLE 前缀 | `ENABLE_DEBUG`, `DISABLE_CACHE` |
| **错误码** | ERROR/ERR 前缀 | `ERR_FILE_NOT_FOUND`, `ERROR_INVALID_ARG` |

### 避免冲突

使用项目或模块前缀：

```c
#define PROJECT_VERSION "1.0.0"
#define PROJECT_MAX_BUFFER 1024
#define PROJECT_DEFAULT_PORT 8080
```

## 常见宏定义类型

### 1. 常量宏

```c
#define MAX_ARRAY_SIZE 100
#define MIN_VALUE 0
#define VERSION "1.2.3"
#define PI 3.14159
#define TRUE 1
#define FALSE 0
```

### 2. 计算宏

```c
// 简单计算
#define SQUARE(x) ((x) * (x))

// 条件判断
#define MAX(a, b) ((a) > (b) ? (a) : (b))
#define MIN(a, b) ((a) < (b) ? (a) : (b))

// 位操作
#define SET_BIT(var, bit) ((var) |= (1 << (bit)))
#define CLEAR_BIT(var, bit) ((var) &= ~(1 << (bit)))
#define GET_BIT(var, bit) (((var) >> (bit)) & 1)

// 字节操作
#define SWAP(a, b) do { \
    typeof(a) temp = (a); \
    (a) = (b); \
    (b) = temp; \
} while(0)
```

### 3. 条件编译宏

```c
// 调试模式
#ifdef DEBUG
    #define DEBUG_PRINT(fmt, ...) printf(fmt, ##__VA_ARGS__)
#else
    #define DEBUG_PRINT(fmt, ...) do {} while(0)
#endif

// 平台相关
#ifdef _WIN32
    #define PLATFORM_WINDOWS
#elif defined(__linux__)
    #define PLATFORM_LINUX
#else
    #define PLATFORM_UNKNOWN
#endif
```

### 4. 类型定义宏

```c
#define DECLARE_ARRAY(type, name, size) type name[size]
#define DECLARE_POINTER(type, name) type *name

// 使用示例
DECLARE_ARRAY(int, arr, 100);    // int arr[100];
DECLARE_POINTER(char, str);       // char *str;
```

### 5. 字符串处理宏

```c
#define STRINGIFY(x) #x              // 将参数转换为字符串
#define CONCAT(a, b) a ## b          // 连接两个标识符

// 示例
const char *version = STRINGIFY(1.0);  // "1.0"
#define FUNC_NAME CONCAT(my_, func)    // my_func
```

## 最佳实践

### ✅ 应该做的事

1. **始终使用括号**
   ```c
   // ❌ 错误
   #define DOUBLE(x) x * 2
   
   // ✅ 正确
   #define DOUBLE(x) ((x) * 2)
   ```

2. **对多行宏使用 do-while**
   ```c
   #define LOG_ERROR(msg) do { \
       fprintf(stderr, "ERROR: %s\n", (msg)); \
       exit(1); \
   } while(0)
   ```

3. **参数使用括号保护**
   ```c
   #define ADD(a, b) ((a) + (b))        // 正确
   #define MULTIPLY(a, b) (a) * (b)    // 错误：a * (b) * 2 会出问题
   ```

4. **文档说明复杂宏**
   ```c
   // 计算两个数的最大值
   // 会对参数求值两次，避免使用有副作用的表达式
   #define MAX(a, b) ((a) > (b) ? (a) : (b))
   ```

### ❌ 应该避免的事

1. ❌ 不要在宏中使用赋值
   ```c
   #define BAD_MACRO (x = 5)  // 危险！
   ```

2. ❌ 不要忽略括号
   ```c
   #define BAD_CALC x + y * 2  // 容易产生错误
   ```

3. ❌ 避免过于复杂的宏（考虑用函数替代）
   ```c
   // 应该用函数实现复杂逻辑
   inline int complex_operation(int a, int b) {
       return (a > b) ? a * 2 : b / 2;
   }
   ```

4. ❌ 不要忘记使用 `defined()` 进行安全检查
   ```c
   // ❌ 错误
   #if FEATURE_FLAG
   
   // ✅ 正确
   #if defined(FEATURE_FLAG)
   ```

## 示例代码

### 完整的头文件示例

```c
/**
 * @file config.h
 * @brief 应用程序配置头文件
 * @author Your Name
 * @date 2026-03-14
 */

#ifndef CONFIG_H
#define CONFIG_H

/* ==================== 版本信息 ==================== */
#define APP_VERSION "1.0.0"
#define APP_NAME "MyApplication"

/* ==================== 编译配置 ==================== */
#define DEBUG 1
#define ENABLE_LOGGING 1
#define ENABLE_CACHE 1

/* ==================== 系统参数 ==================== */
#define MAX_BUFFER_SIZE 4096
#define MAX_CONNECTIONS 100
#define DEFAULT_PORT 8080
#define TIMEOUT_SECONDS 30

/* ==================== 数据类型定义 ==================== */
typedef unsigned char uint8_t;
typedef unsigned short uint16_t;
typedef unsigned int uint32_t;

/* ==================== 条件编译 ==================== */
#ifdef DEBUG
    #define LOG(fmt, ...) printf("[LOG] " fmt "\n", ##__VA_ARGS__)
    #define DEBUG_ASSERT(x) assert(x)
#else
    #define LOG(fmt, ...)
    #define DEBUG_ASSERT(x)
#endif

/* ==================== 工具宏 ==================== */
#define ARRAY_SIZE(arr) (sizeof(arr) / sizeof((arr)[0]))
#define CONTAINER_OF(ptr, type, member) \
    ((type *)((char *)(ptr) - offsetof(type, member)))

/* ==================== 函数声明 ==================== */
void init_config(void);
void print_config(void);

#endif // CONFIG_H
```

## 检查清单

创建头文件时，使用此清单确保符合规范：

- [ ] 使用了头文件保护 (`#ifndef` 或 `#pragma once`)
- [ ] 所有宏名称都是全大写
- [ ] 常量宏有适当的前缀
- [ ] 所有计算宏都用括号保护
- [ ] 避免了重复的宏定义
- [ ] 复杂宏都有注释说明
- [ ] 包含了必要的 `#include` 指令
- [ ] 没有在宏中使用带副作用的表达式
- [ ] 使用了 `defined()` 进行条件判断
