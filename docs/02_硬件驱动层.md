# 第2章：硬件驱动层 (01_hal_drivers)

> **本章目标**：理解 HAL 层如何封装芯片寄存器，为上层提供简洁的硬件操作 API
> **对应代码**：`BanBox/src/banux/01_hal_drivers/`

---

## 2.1 HAL 层概述

HAL (Hardware Abstraction Layer，硬件抽象层) 是最底层的用户态代码，直接封装 MVSilicon SDK 中的寄存器操作，向上层提供统一、简洁的 API。

**设计原则**：
- **薄封装**：只做必要的参数校验和单位转换，不引入额外抽象
- **零依赖**：不依赖上层任何模块，仅依赖 SDK 头文件
- **统一接口**：所有 HAL 函数以 `HAL_` 前缀命名

---

| 模块 | 目录 | 对应硬件 | 功能 |

## 2.3 ADC HAL

**文件**：`adc/hal_adc.h`

### 功能说明

提供单次 ADC 采样和电压转换，主要用于电池电压检测。

### 关键 API

```c
// 单次采样，返回 0~4095 的原始值
uint16_t HAL_ADC_SingleRead(HAL_ADC_Channel_t channel);

// 原始值转电压（mV），基于 3.3V 参考
uint32_t HAL_ADC_ToVoltage(uint16_t adcValue);

// 一步获取通道电压（mV）
uint32_t HAL_ADC_GetVoltage(HAL_ADC_Channel_t channel);
```

### 通道定义

```c
HAL_ADC_CH_A0   // GPIO A0
HAL_ADC_CH_A1   // GPIO A1
// ... 最多支持 32 个通道
HAL_ADC_CH_A31  // GPIO A31
```

### 使用示例

```c
// 读取电池电压
uint16_t raw = HAL_ADC_SingleRead(HAL_ADC_CH_A5);
uint32_t voltage_mv = HAL_ADC_ToVoltage(raw);
// 或一步完成：
uint32_t voltage_mv = HAL_ADC_GetVoltage(HAL_ADC_CH_A5);
```

## 2.4 音频设置模块

**文件**：`adc/audio_setting.h`、`adc/audio_setting.c`

### 功能说明

控制 ADC 音频输入的硬件音量。芯片的 ADC 音频通道有独立的硬件增益控制寄存器，支持 0x001 (-72dB) 到 0xFFF (0dB) 的精细调节。

### 音频 ADC 通道模型

```
ADC0 立体声
├── 左声道 → Mic1  (麦克风1)
└── 右声道 → Mic2  (麦克风2)

ADC1 立体声
├── 左声道 → Guitar1 (吉他/Line-In)
└── 右声道 → Guitar2 (吉他/Line-In)
```

### 关键 API

```c
// ===== Mic1 (ADC0 左声道) =====
void     AudioSetting_SetMic1Volume(uint16_t hwVolume);     // 设置硬件音量值
uint16_t AudioSetting_GetMic1Volume(void);                  // 获取当前硬件音量值
void     AudioSetting_SetMic1VolumePercent(uint8_t pct);    // 设置百分比音量 (0-100)
uint8_t  AudioSetting_GetMic1VolumePercent(void);           // 获取百分比音量

// ===== Mic2 (ADC0 右声道) =====
// ... 同样的接口

// ===== Guitar1 (ADC1 左声道) =====
// ... 同样的接口

// ===== Guitar2 (ADC1 右声道) =====
// ... 同样的接口
```

### 音量范围参考

| 百分比 | 硬件值 | 衰减 | 典型场景 |
|--------|--------|------|----------|
| 100% | 0xFFF | 0 dB | 低电平信号 |
| 75% | 0xBFF | ~-3 dB | 正常乐器 |
| 50% | 0x7FF | ~-6 dB | 高电平信号 |
| 25% | 0x3FF | ~-12 dB | 削波时降低 |
| 1% | 0x001 | -72 dB | 几乎静音 |

### 使用示例

```c
// 设置麦克风音量为 75%
AudioSetting_SetMic1VolumePercent(75);

// 设置吉他输入为 50%（防止削波）
AudioSetting_SetGuitar1VolumePercent(50);
```

## 2.5 GPIO HAL

**文件**：`gpio/hal_gpio.h`

### 功能说明

封装 GPIO 寄存器的基本操作：输入/输出方向、电平设置、上拉/下拉控制。

### 端口与引脚

```
HAL_GPIO_A    → GPIO_A 端口 (32 pin: A0-A31)
HAL_GPIO_B    → GPIO_B 端口 (32 pin: B0-B31)

HAL_PIN_0  ~ HAL_PIN_31
```

### 关键 API

```c
// ===== 基本操作 =====
void     HAL_GPIO_SetOutput(uint8_t port, uint8_t pin);    // 设为输出
void     HAL_GPIO_SetInput(uint8_t port, uint8_t pin);     // 设为输入
void     HAL_GPIO_SetHigh(uint8_t port, uint8_t pin);      // 输出高电平
void     HAL_GPIO_SetLow(uint8_t port, uint8_t pin);       // 输出低电平
void     HAL_GPIO_Toggle(uint8_t port, uint8_t pin);       // 翻转电平
uint8_t  HAL_GPIO_Read(uint8_t port, uint8_t pin);         // 读取输入电平

// ===== 上下拉控制 =====
void     HAL_GPIO_PullUpEnable(uint8_t port, uint8_t pin);
void     HAL_GPIO_PullUpDisable(uint8_t port, uint8_t pin);
void     HAL_GPIO_PullDownEnable(uint8_t port, uint8_t pin);
void     HAL_GPIO_PullDownDisable(uint8_t port, uint8_t pin);
```

### 使用示例

```c
// LED 闪烁 (B3 设为输出)
HAL_GPIO_SetOutput(HAL_GPIO_B, HAL_PIN_3);
HAL_GPIO_SetHigh(HAL_GPIO_B, HAL_PIN_3);   // LED ON
HAL_GPIO_SetLow(HAL_GPIO_B, HAL_PIN_3);    // LED OFF

// 按键检测 (A7 设为输入，使能上拉)
HAL_GPIO_SetInput(HAL_GPIO_A, HAL_PIN_7);
HAL_GPIO_PullUpEnable(HAL_GPIO_A, HAL_PIN_7);
if (HAL_GPIO_Read(HAL_GPIO_A, HAL_PIN_7) == 0) {
    // 按键按下（上拉时低电平 = 按下）
}
```

## 2.6 SPI HAL

**文件**：`spi/hal_spi.h`

### 功能说明

封装 SPI Master 控制器的基本操作，支持标准 SPI 和 QSPI (4线) 模式。

### 关键 API

```c
// 初始化 SPI 控制器
void HAL_SPI_Init(HAL_SPI_Module_t module, uint32_t freq_hz, HAL_SPI_Mode_t mode);

// 单字节收发
uint8_t HAL_SPI_Transfer(HAL_SPI_Module_t module, uint8_t data);

// 批量收发
void HAL_SPI_TransferBuf(HAL_SPI_Module_t module, 
                         uint8_t *tx_buf, uint8_t *rx_buf, uint32_t len);

// 快速发送（忽略接收）
void HAL_SPI_SendBuf(HAL_SPI_Module_t module, uint8_t *buf, uint32_t len);

// 4-bit QSPI 收发
void HAL_SPI_QspiTransfer(HAL_SPI_Module_t module, 
                          uint8_t *tx, uint8_t *rx, uint32_t len);
```

### 模块定义

```
HAL_SPI0  → Flash (QSPI, 80MHz, 4-bit)
HAL_SPI1  → PSRAM (QSPI)
HAL_SPI2  → NAND Flash (QSPI)
HAL_SPI3  → LCD ST7735 (SPI)
```

## 2.7 SDIO HAL

**文件**：`sdio/hal_sdio.h`、`sdio/hal_sdio.c`

### 功能说明

封装 SDIO 接口，支持 SD 卡的初始化和读写操作。

### 关键 API

```c
// 初始化 SDIO 控制器
int HAL_SDIO_Init(uint32_t freq_hz);

// 发送命令 + 读取响应
int HAL_SDIO_SendCmd(uint8_t cmd_idx, uint32_t arg, uint32_t *resp);

// 数据读写
int HAL_SDIO_ReadBlocks(uint8_t *buf, uint32_t start_block, uint32_t num_blocks);
int HAL_SDIO_WriteBlocks(uint8_t *buf, uint32_t start_block, uint32_t num_blocks);

// 状态查询
int HAL_SDIO_IsCardInserted(void);
uint64_t HAL_SDIO_GetCapacity(void);
```

## 2.8 PSRAM 堆管理

**文件**：`psram_heap.h`

### 功能说明

PSRAM (ESP-PSRAM64H) 是外挂的 8MB SPI PSRAM。本模块基于 FreeRTOS `heap_5.c` 将其注册为一个额外的内存区域，可以使用 `pvPortMalloc()` 统一分配。

### 使用方式

```c
// PSRAM 会自动注册到 FreeRTOS heap_5 的内存区域列表中
// 以下代码即可从 PSRAM 分配内存（与大堆统一管理）：
void *buf = pvPortMalloc(1024 * 1024);  // 从 PSRAM 分配 1MB
```

> **注意**：PSRAM 的访问速度比内部 SRAM 慢，仅适合大块数据存储（如音频 Buffer），不适合频繁随机访问的小对象。
