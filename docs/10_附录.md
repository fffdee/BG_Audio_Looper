## 10.1 术语表

| 术语 | 全称 | 中文 | 说明 |
|------|------|------|------|
| **HAL** | Hardware Abstraction Layer | 硬件抽象层 | 封装寄存器操作的最底层驱动 |
| **VFS** | Virtual File System | 虚拟文件系统 | 将设备参数映射为文件节点 |
| **BLE** | Bluetooth Low Energy | 低功耗蓝牙 | 蓝牙 5.x 低功耗模式 |
| **A2DP** | Advanced Audio Distribution Profile | 高级音频分发协议 | 蓝牙立体声音频流 |
| **HFP** | Hands-Free Profile | 免提协议 | 蓝牙免提通话 |
| **AVRCP** | Audio/Video Remote Control Profile | 音视频遥控协议 | 蓝牙媒体控制 |
| **SPP** | Serial Port Profile | 串口协议 | 蓝牙虚拟串口 |
| **SBC** | Subband Codec | 子带编码 | A2DP 音频编解码器 |
| **AEC** | Acoustic Echo Cancellation | 回声消除 | 消除喇叭→Mic 的回声 |
| **DRC** | Dynamic Range Control | 动态范围控制 | 压缩/限幅音频动态范围 |
| **EQ** | Equalizer | 均衡器 | 调节频段增益 |
| **DAC** | Digital-to-Analog Converter | 数模转换器 | 数字音频→模拟信号 |
| **ADC** | Analog-to-Digital Converter | 模数转换器 | 模拟信号→数字音频 |
| **DMA** | Direct Memory Access | 直接内存访问 | 无需 CPU 干预的数据搬运 |
| **FIFO** | First In, First Out | 先进先出队列 | 音频数据缓冲队列 |
| **PCM** | Pulse Code Modulation | 脉冲编码调制 | 原始数字音频格式 |
| **WAV** | Waveform Audio File Format | 波形音频文件 | 含 RIFF 头的 PCM 文件格式 |
| **MP3** | MPEG Audio Layer III | MP3 音频 | 有损压缩音频格式 |
| **Looper** | Loop Station | 循环乐句工作站 | 录制→循环播放→叠加 |
| **Overdub** | Overdubbing | 叠加录音 | 在播放的循环上录制新内容 |
| **Effect Graph** | - | 效果器图 | 节点图形式的音频处理管线 |
| **PSRAM** | Pseudo Static RAM | 伪静态随机存储器 | 外挂 SPI 接口的 8MB RAM |
| **NOR Flash** | - | NOR 闪存 | 支持 XIP (就地执行) |
| **NAND Flash** | - | NAND 闪存 | 大容量存储，支持 FAT32 |
| **FAT32** | File Allocation Table 32 | FAT32 文件系统 | NAND Flash 上的文件系统 |
| **CDC** | Communication Device Class | 通信设备类 | USB 虚拟串口 |
| **XIP** | eXecute In Place | 就地执行 | 直接从 Flash 取指令执行 |
| **GATT** | Generic Attribute Profile | 通用属性协议 | BLE 的服务/特征值模型 |
| **SPI** | Serial Peripheral Interface | 串行外设接口 | 四线同步串行总线 |
| **QSPI** | Quad SPI | 四线 SPI | 4-bit 并行数据传输的 SPI |
| **SDIO** | Secure Digital I/O | SD 输入输出 | SD 卡专用总线接口 |
| **GPIO** | General Purpose I/O | 通用输入输出 | 可编程数字引脚 |
| **RTOS** | Real-Time Operating System | 实时操作系统 | FreeRTOS v8.0.0 |
| **ISR** | Interrupt Service Routine | 中断服务例程 | 外设中断处理函数 |
| **IVB** | Interrupt Vector Base | 中断向量基址 | 指向异常向量表起始地址 |
| **MPU** | Memory Protection Unit | 内存保护单元 | 设置内存区域访问权限 |

## 10.2 Flash 完整布局

```
地址范围                         大小        内容
────────────────────────────────────────────────────────────
0x00000000 - 0x0003FFFF         256 KB     Bootloader
  0x00000000 - 0x000000FF       256 B      异常向量表
  0x00000100 - 0x0003FFFF       剩余       启动引导程序

0x00040000 - 0x0023FFFF         2 MB       Partition A (APP)

0x00240000 - 0x0043FFFF         2 MB       Partition B (APP)

0x00440000 - 0x00440FFF         4 KB       分区标志区
  0x00440000 - 0x00440000+1     1 B        active_part (0=A, 1=B)
  0x00440001 - 0x00440001+1     1 B        boot_fail_cnt

0x00441000 - 0x00FFFFFF         剩余       用户数据区 (NAND Flash)
```

## 10.4 DAC/ADC 音频通道映射

```
链 路            物理接口        数据路径
──────────────────────────────────────────────
DAC0 Left       引脚出          Effect Graph → DAC0_L → 喇叭
DAC0 Right      引脚出          Effect Graph → DAC0_R → 耳机左
DAC1 Left       引脚出          Effect Graph → DAC1_L → 耳机右
DAC1 Right      引脚出          Effect Graph → DAC1_R → 辅助输出

ADC0 Left       引脚入          吉他/LineIn → ADC0_L → Effect Graph
ADC0 Right      引脚入          Mic 1 → ADC0_R → Effect Graph
ADC1 Left       引脚入          电位器 → ADC1_L → 音量检测
ADC1 Right      引脚入          Mic 2 → ADC1_R → Effect Graph
```
