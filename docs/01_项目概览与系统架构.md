## 1.1 项目简介

**BG_Audio_Looper** 是一个基于 MVSilicon BP10 系列芯片的 **专业音频 Loop Station（循环乐句工作站）** 嵌入式固件项目。

### 核心功能

| 功能模块 | 说明 |
|----------|------|
| **音频 Looper** | 多轨循环录制/播放/叠加，支持 Flash/PSRAM 存储 |
| **实时音频效果器** | EQ / DRC / Reverb / Echo / 变声 等 20+ 种效果 |
| **蓝牙音频** | 经典蓝牙 A2DP/HFP/AVRCP + 低功耗蓝牙 BLE |
| **USB 音频** | USB Audio Class 声卡模式，支持录制和回放 |
| **乐器/Mic 输入** | 双 ADC 通道，支持吉他 Line-In 和麦克风输入 |
| **节拍器 & 鼓机** | 内置节拍器和 MIDI 鼓机/BanGTsynth 合成器 |
| **手机 App 控制** | BLE 协议与手机 App 通信，调整效果参数 |
| **Shell 命令行** | 通过 USB CDC / BLE 访问完整的调试和控制 Shell |

## 1.2 硬件平台

### 芯片规格

| 参数 | 规格 |
|------|------|
| **芯片型号** | MVSilicon BP10 系列 |
| **CPU 核心** | Andes NDS32 (N903-S) |
| **CPU 主频** | 120 MHz |
| **指令集** | 32位 RISC，支持 ZOL 零开销循环 |
| **FPU** | 硬件浮点单元 |
| **SRAM** | 16 KB ISRAM + 16 KB DSRAM + 8 KB DLM |
| **外置 PSRAM** | ESP-PSRAM64H (8 MB)，SPI 接口 |
| **Flash** | W25Qxx NOR Flash (外挂) + W25N02 NAND Flash |
| **DAC** | 24位立体声 DAC × 2 (DAC0 + DAC1) |
| **ADC** | 12位 SAR ADC，支持 Line-In / Mic 输入，最多 2 组立体声 |
| **蓝牙** | 双模：Classic BT (BR/EDR) + BLE 5.x |
| **USB** | USB 2.0 OTG，支持 Audio Class + CDC |
| **GPIO** | GPIO_A (32 pin) + GPIO_B (32 pin)，共 64 个 |
| **I2S** | 1 路 I2S 数字音频接口 |
| **SPDIF** | 1 路光纤数字音频接口 |
| **SPI** | SPI Master，支持 4-bit QSPI，最大 80MHz |
| **SDIO** | SD 卡接口 |
| **定时器** | 多路 32位 Timer |
| **看门狗** | 硬件看门狗 |

### 各层职责

| 层级 | 职责 | 依赖关系 |
|------|------|----------|
| **06_app** | 应用业务逻辑：音频 I/O 主循环、效果参数管理、开机音乐 | 依赖 05→02 |
| **05_component** | 可复用组件：EffectGraph 音频管线、Looper、合成器、GUI | 依赖 04→02 |
| **04_shell_commands** | 人机交互：Shell 解析器 + 所有调试/控制命令模块 | 依赖 03→02 |
| **03_driver_framework** | 基础设施：VFS、设备模型、事件系统、驱动注册 | 依赖 02 |
| **02_device_drivers** | 外设驱动：蓝牙、Flash、LCD、电源、音频、USB | 依赖 01 |
| **01_hal_drivers** | 硬件适配：将 SDK 寄存器操作封装为标准 HAL API | 依赖 SDK |

## 1.4 音频数据流框图

```
                       ┌─────────── EFFECT GRAPH (音频效果管线) ────────────┐
                       │                                                    │
  [吉他] ──→ ADC0 ────→│→ ADC0_Source ─→ Expander ─→ EQ ─→ DRC ─→ Reverb ─→│→ DAC0 → 喇叭
  [Mic]  ──→ ADC1 ────→│→ ADC1_Source ─→ Expander ─→ EQ ─→ DRC ────────────→│→ DAC1 → 耳机
  [USB]  ──→ USB_Audio →│→ USB_Source  ─→ Mixer ────────────────────────────→│→ USB  → PC录音
  [蓝牙] ──→ BT_A2DP ──→│→ BT_Source   ─→ Mixer ──→ EQ ──→ DRC ────────────→│
  [节拍器]──────────────→│→ Metronome_Source                                │
  [Looper]──────────────→│→ Looper_Source (播放已录制片段)                    │
                         │                                                    │
                         │              ┌─ Looper_Sink (录制到 Flash/PSRAM)   │
                         └──────────────┴────────────────────────────────────┘

  【特殊模式 - 提示音播放】
  [MP3/WAV数组] ─→ 解码器 (malloc 19KB) ─→ 直接写 DAC FIFO (绕过 Effect Graph)
```

### 数据流说明

1. **正常音频处理**：所有音源 → Effect Graph 节点链 → DAC 输出
2. **Looper 录制**：混音后的数据 → Looper Sink → Flash/PSRAM 存储
3. **Looper 播放**：Flash/PSRAM → Looper Source → 混回 Effect Graph
4. **提示音播放**：const 数组数据 → 解码器 → **独占** DAC（设置 `g_remind_sound_active=1` 暂停 Effect Graph）
5. **USB 双向音频**：USB Source（PC 播放） + USB Sink（录音回 PC）

## 1.5 系统启动流程概览

```
硬件上电
   │
   ▼
Bootloader (0x000000)
   ├── 硬件初始化（时钟/PLL/UART/SPI Flash）
   ├── 读取分区标志 → 选择 Partition A/B
   ├── 复制 .data 段到 SRAM
   ├── 设置 Magic = 0xDEADBEEF（交接协议）
   └── 跳转到 APP 入口 ──────────────────────────┐
                                                  ▼
                                           BanBox APP (0x040000)
                                              ├── UART 重新初始化
                                              ├── FreeRTOS 初始化
                                              ├── DrvFramework_FullInit()
                                              │   ├── VFS 初始化
                                              │   ├── Flash 驱动注册
                                              │   ├── LCD/PSRAM/SD/Battery 注册
                                              │   └── Shell 命令注册
                                              ├── 创建 MainTask
                                              └── vTaskStartScheduler()
                                                  │
                                                  ▼
                                              MainTask()
                                              ├── 电源管理初始化
                                              ├── BG_AudioManager.Audio_Init()
                                              │   ├── USB 设备初始化
                                              │   ├── DAC/ADC 初始化
                                              │   ├── 音频效果器初始化
                                              │   ├── 蓝牙协议栈启动
                                              │   ├── ShellIO 管理器
                                              │   └── Effect Graph 启动
                                              └── 主循环
                                                  ├── Audio_Loop() 音频处理
                                                  ├── Shell_Process() 命令处理
                                                  └── BG_UI.Update() 界面刷新
```

## 1.6 核心技术栈

| 技术 | 说明 |
|------|------|
| **RTOS** | FreeRTOS v8.0.0，抢占式调度，1ms Tick |
| **编译器** | Andes ND32 GCC (riscv32-elf-gcc) |
| **文件系统** | 自制轻量 VFS (Virtual File System) |
| **音频解码** | 内置 MP3/WAV 解码器 |
| **蓝牙协议栈** | MVSilicon 私有蓝牙栈 |
| **音频管线** | 自研 Effect Graph（类 JACK/PipeWire 的节点图） |
| **Shell** | 自研命令行框架，支持 CDC + BLE 双通道 |
| **GUI** | BanGUI 轻量图形框架（基于 ST7735 LCD） |
| **升级** | 双分区 A/B 升级 + USB CDC 固件传输 |
