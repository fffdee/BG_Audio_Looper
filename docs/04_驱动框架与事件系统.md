## 4.1 驱动框架层概述

03 层是整个系统的 **基础设施层**，提供三大核心能力：

| 组件 | 功能 | 类比 |
|------|------|------|
| **VFS 虚拟文件系统** | 统一的文件/设备访问接口 | Linux `/dev` + `/proc` |
| **设备注册模型** | 驱动自动发现和注册 | Linux 驱动模型 |
| **事件发布订阅系统** | 模块间松耦合通信 | ROS Topic |

```
        ┌─────────────────────────────────┐
        │       应用层 / Shell 命令         │
        ├───────────┬──────────┬──────────┤
        │  VFS 接口  │ 设备接口  │ 事件接口  │
        ├───────────┴──────────┴──────────┤
        │    03_driver_framework           │
        ├──────────────────────────────────┤
        │    02_device_drivers 设备驱动     │
        └──────────────────────────────────┘
```

## 4.2 驱动初始化流程

由 `drv_init.c` 中的 `DrvFramework_FullInit()` 统一驱动：

```c
void DrvFramework_FullInit(void) {
    // ===== 阶段 1：核心框架初始化 =====
    DrvFramework_Init();
    //   ├── Vfs_Init()            # VFS 核心初始化
    //   ├── DrvFs_Init()          # 创建 /driver 目录树
    //   ├── ShellFs_Init()        # 创建 /bin Shell命令目录
    //   └── DrvDevice_Init()      # 设备管理系统初始化

    // ===== 阶段 2：Flash 管理器（不依赖 VFS）=====
    BG_flash_manager.Init();
    BG_FlashMgr.Init();

    // ===== 阶段 3：注册所有硬件驱动到 VFS =====
    DrvFramework_RegisterAll();
    //   ├── St7735_DrvRegister()  → /driver/spi/st7735/
    //   ├── W25qxx_DrvRegister()  → /driver/spi/w25qxx/
    //   ├── W25n02_DrvRegister()  → /driver/spi/w25n02/
    //   ├── Psram_DrvRegister()   → /driver/spi/psram/
    //   ├── SDCard_DrvRegister()  → /driver/sdio/sdcard/
    //   ├── Battery_DrvRegister() → /driver/power/battery/
    //   ├── UsbCdc_DrvRegister()  → /driver/usb/cdc/
    //   ├── BtVfs_Init + Mount    → /driver/bt/
    //   ├── BleVfs_Init + Mount   → /driver/ble/
    //   └── ShellFs_RegisterAllCommands()  → /bin/ 系统命令
}
```

### VFS 目录树结构

```
/
├── driver/                  # 硬件驱动目录
│   ├── spi/
│   │   ├── st7735/          # LCD 驱动参数 (VFS 文件节点)
│   │   ├── w25qxx/          # NOR Flash 参数
│   │   ├── w25n02/          # NAND Flash 参数
│   │   └── psram/           # PSRAM 参数

│   │   └── sdcard/          # SD 卡参数

│   ├── bt/                  # 经典蓝牙参数 (MAC/名称/状态)

└── bin/                     # Shell 命令目录
    ├── sys                  # 系统命令 (ps, free, reboot...)
    ├── audio                # 音频命令

    ├── lcd                  # LCD 命令
    ├── looper               # Looper 命令
    ├── flash                # Flash 命令
    ├── battery              # 电池命令
    ├── bt                   # 蓝牙命令
    ├── remind               # 提示音命令
    ├── pwr_music            # 开机音乐命令
    └── ... (30+ 个命令模块)
```

## 4.3 VFS 虚拟文件系统

### 设计理念

VFS 是一个 **轻量级虚拟文件系统**，将硬件设备参数映射为文件节点。上层通过统一的 `open/read/write/close` 接口操作设备。

### 核心数据结构

```c
// VFS 节点
typedef struct VfsNode {
    const char *name;               // 节点名称
    void       *parent;             // 父节点
    void       *child;              // 子节点链表
    void       *data;               // 用户数据
    int       (*open)(void *file);
    int       (*close)(void *file);
    int       (*read)(void *file, void *buf, int len);
    int       (*write)(void *file, void *buf, int len);
    int       (*ioctl)(void *file, int cmd, void *arg);
} VfsNode_t;
```

### 关键 API

```c
// 文件操作
void* Vfs_Open(const char *path);
int   Vfs_Read(void *file, void *buf, int len);
int   Vfs_Write(void *file, void *buf, int len);
int   Vfs_Close(void *file);

// 节点管理
void  Vfs_Mount(const char *path, VfsNode_t *node);     // 挂载节点
VfsNode_t* Vfs_CreateNode(const char *name);             // 创建节点
int   Vfs_AddChild(VfsNode_t *parent, VfsNode_t *child); // 添加子节点
```

### 实际使用：读取电池电量

```c
// 用户代码只需要知道路径
void *f = Vfs_Open("/driver/power/battery/voltage");
char buf[32];
Vfs_Read(f, buf, sizeof(buf));   // 得到 "4100mV"
Vfs_Close(f);
```

等价于 Shell 命令：

```bash
cat /driver/power/battery/voltage
```

## 4.4 设备注册模型

### 类 Linux 设备驱动模型

```c
// 驱动设备描述符
typedef struct {
    const char *name;           // 设备名
    const char *desc;           // 描述
    DrvBusType_t bus;           // 总线类型 (SPI/I2C/I2S/SDIO/...)
    int (*init)(void);          // 初始化
    int (*deinit)(void);        // 反初始化
    int (*open)(void *file);
    int (*close)(void *file);
    int (*read)(void *file, void *buf, int len);
    int (*write)(void *file, void *buf, int len);
    int (*ioctl)(void *file, int cmd, void *arg);
    DrvParam_t *params;         // 参数列表
    void *privData;             // 私有数据
} DrvDevice_t;
```

### 注册宏

```c
// 定义驱动
DRV_DEVICE_DEF(st7735, "ST7735 LCD", DRV_BUS_SPI, st7735_init);

// 定义参数
DRV_PARAM_RO(st7735, "width",  "%d",  config.width);
DRV_PARAM_RO(st7735, "height", "%d",  config.height);
DRV_PARAM_RW(st7735, "brightness", "%d", brightness_set, brightness_get);
```

### 注册流程

```
St7735_DrvRegister()
  └── DrvDevice_Register(&drv_st7735)
        └── 在 /driver/spi/ 下创建 st7735/ 目录
              └── 注册 width / height / brightness 文件节点
```

## 4.5 事件发布订阅系统

### 设计理念

类 ROS (Robot Operating System) 的 **Topic 发布-订阅模型**，实现模块间松耦合通信：

```
┌──────────┐   publish("EVT_BTN_CLICK")   ┌──────────────┐
│ 按键驱动  │ ─────────────────────────────→│  事件总线     │
└──────────┘                               │  (Topic表)   │
                                           │              │
┌──────────┐  subscribe("EVT_BTN_CLICK")  │              │
│ UI更新    │ ←─────────────────────────────│              │
└──────────┘                               └──────────────┘
                                           ┌──────────────┐
                                           │ Looper控制    │
                                           └──────────────┘
```

### 话题定义 (`bg_event_topics.h`)

| 话题范围 | 域 | 典型事件 |
|----------|-----|----------|
| `0x0000-0x001F` | **按钮** | CLICK, DOUBLE_CLICK, LONG_PRESS, REPEAT |
| `0x0020-0x003F` | **编码器** | CW (顺时针), CCW (逆时针), CLICK |
| `0x0040-0x005F` | **音频** | LINE_IN, MIC_IN, GUITAR_IN, HP_OUT, VOLUME_CHG, CLIP |
| `0x0060-0x007F` | **系统** | BT_CONNECT, BT_DISCONNECT, BT_STREAMING, BATTERY_LOW, USB_PLUG |
| `0x0080-0x009F` | **MIDI** | NOTE_ON, NOTE_OFF, CC, PITCH_BEND |
| `0x00A0-0x00BF` | **Looper** | REC_START, REC_STOP, PLAY_START, PLAY_STOP, OVERDUB, UNDO |
| `0x00C0-0x00DF` | **BLE** | CONNECTED, DISCONNECTED, DATA_RECEIVED |

### 关键 API

```c
// 订阅事件（在文件作用域声明即可自动注册）
BG_EVT_SUB(EVT_BTN_CLICK, on_button_click);

// 发布事件
BG_EVT_PUB(EVT_BTN_CLICK);                         // 无数据
BG_EVT_PUB_DATA(EVT_BTN_CLICK, &data, sizeof(data)); // 带数据

// 也可以直接调用
void BG_Event_Publish(uint16_t topic, void *data, uint16_t len);
```

### 回调函数签名

```c
// 订阅者回调：topic=事件ID, data=事件数据, len=数据长度
void my_callback(uint16_t topic, void *data, uint16_t len);
```

### 使用示例 (app_event_example.c)

```c
// ===== 订阅者 1：按钮按下 → 触发 Looper 录制 =====
static void on_btn_click(uint16_t topic, void *data, uint16_t len) {
    (void)topic; (void)data; (void)len;
    Looper_StartRecording();
}
BG_EVT_SUB(EVT_BTN_CLICK, on_btn_click);

// ===== 订阅者 2：蓝牙连接 → 更新 LED 指示灯 =====
static void on_bt_connect(uint16_t topic, void *data, uint16_t len) {
    LED_SetBlue(1);   // 蓝灯亮 = 已连接
}
BG_EVT_SUB(EVT_SYS_BT_CONNECT, on_bt_connect);

// ===== 订阅者 3：低电量 → 播放警告音 =====
static void on_battery_low(uint16_t topic, void *data, uint16_t len) {
    RemindSound_PlayByName("low_battery");
}
BG_EVT_SUB(EVT_SYS_BATTERY_LOW, on_battery_low);
```

### 系统限制

| 参数 | 值 |
|------|-----|
| 最大订阅槽 | 32 |
| 最大话题数 | 不限 (16-bit ID) |
| 通配符 | `BG_EVT_TOPIC_ANY` (0xFFFF)，订阅所有事件 |
| RAM 开销 | ~192 bytes |
