## 6.2 AudioCore 框架 (app_config.h)

### 6.2.1 核心概念

AudioCore 是一个 **Source-Sink 模型**的音频框架：

```
 ┌──────── Source 源 ────────┐          ┌──────── Sink 汇 ─────────┐
 │  ADC0 (吉他)              │          │  DAC0 (喇叭)              │
 │  ADC1 (麦克风)            │  ────→   │  DAC1 (耳机)              │
 │  USB Audio (PC播放)       │  效果器   │  USB Audio (录音回PC)     │
 │  BT A2DP (蓝牙音频)       │  管线     │  Looper Record (录制到Flash)│
 │  Metronome (节拍器)       │          │                          │
 │  Looper Play (片段回放)   │          │                          │
 └───────────────────────────┘          └──────────────────────────┘
```

### 6.2.2 音频源 (AudioCoreSource)

```c
typedef struct {
    uint8_t  Index;                    // 源编号
    uint8_t  PcmFormat;               // PCM 格式 (sign/stereo)
    uint8_t  Enable;                   // 使能标志
    uint8_t  IsStreamData;            // 是否流式数据

    // 数据获取回调
    AudioCoreDataGetFunc    FuncDataGet;      // 读取数据
    AudioCoreDataLenGetFunc FuncDataGetLen;   // 获取可用数据长度

    // PCM 缓冲区
    int16_t *PcmInBuf;                  // 输入 PCM 缓冲

    // 音量控制
    uint16_t PreGain;                   // 前置增益
    uint16_t LeftVol;                   // 左声道目标音量
    uint16_t RightVol;                  // 右声道目标音量
    uint16_t LeftCurVol;                // 左声道当前音量 (平滑过渡)
    uint16_t RightCurVol;               // 右声道当前音量 (平滑过渡)
    uint8_t  LeftMuteFlag;             // 左声道静音标志
    uint8_t  RightMuteFlag;            // 右声道静音标志
} AudioCoreSource;
```

**音量平滑过渡**：`CurVol` 每帧向 `Vol` 逼近，避免音量突变产生爆音。

### 6.2.3 音频汇 (AudioCoreSink)

```c
typedef struct {
    uint8_t  Index;
    uint8_t  PcmFormat;
    uint8_t  Enable;
    uint8_t  StreamDataState;

    // 数据输出回调
    AudioCoreDataSetFunc         FuncDataSet;          // 写数据
    AudioCoreDataSpaceLenSetFunc FuncDataSpaceLenGet;  // 获取 FIFO 剩余空间

    // PCM 输出缓冲区
    int16_t *PcmOutBuf;

    // 音量控制 (同 Source)
    uint16_t LeftVol, RightVol;
    uint16_t LeftCurVol, RightCurVol;
    uint8_t  LeftMuteFlag, RightMuteFlag;
} AudioCoreSink;
```

### 6.2.4 音频上下文 (AudioCoreContext)

```c
typedef struct {
    AudioCoreSource      AudioSource[4];    // 最多 4 个音源
    AudioCoreSink        AudioSink[...];    // 多个输出
    AudioCoreProcessFunc AudioEffectProcess; // 效果处理回调
    uint32_t             SampleRate;        // 采样率
} AudioCoreContext;
```

## 6.3 效果器参数系统 (ctrlvars.h/c)

### 6.3.1 全局控制变量

`gCtrlVars` 是一个巨大的全局结构体，包含所有效果器节点的运行时参数。每个效果器节点是一个 **EffectUnit**：

```c
typedef struct {
    uint8_t  enable;      // 使能/旁通
    uint8_t  type;        // 效果类型子模式
    uint16_t preset;      // 预设编号
    uint8_t *param;       // 参数数组指针
    void    *ct;          // 效果器控制结构体指针 (运行时分配)
} EffectUnit;

// 全局控制变量
typedef struct {
    EffectUnit  eq_unit;           // EQ 均衡器
    EffectUnit  drc_unit;          // DRC 动态范围控制
    EffectUnit  reverb_unit;       // Reverb 混响
    EffectUnit  echo_unit;         // Echo 回声
    EffectUnit  howling_unit;      // 啸叫抑制
    EffectUnit  noise_gate_unit;   // 噪声门
    EffectUnit  expander_unit;     // 扩展器
    // ... 更多效果器单元
    uint16_t    master_volume;     // 主音量
    uint8_t     current_mode;      // 当前效果模式
} CtrlVars_t;
```

## 6.4 音频 I/O 管理器 (bg_audio_io_manager.c)

### 6.4.1 概述

`BG_AudioIO_Manager` 是音频子系统的 **总控模块**，约 74KB 的源文件，是整个项目最核心的文件之一。

### 6.4.2 全局实例

```c
BG_Audio_Io_Manager BG_AudioManager = {
    .Audio_Init  = BG_audio_Init,      // 初始化函数
    .Audio_Loop  = Audio_loop,          // 主循环函数
};
```

### 6.4.3 初始化流程 (`BG_audio_Init`)

```
BG_audio_Init(SampleRate)
│
├── 1. InitUSBDevice()          # USB Audio + Mic + CDC 复合设备
│
├── 2. InitDAC(SampleRate)      # 初始化 DAC0/DAC1，设置输出模式
│
├── 3. InitADC0LineIn(SampleRate)   # ADC0 → Guitar/LineIn
│
├── 4. InitADC1Mic(SampleRate)      # ADC1 → Mic
│
├── 5. 开机消噪序列
│   ├── DAC/ADC 全部静音
│   ├── 等待 300ms (VCOM 电容稳定)
│   └── 解除静音
│
├── 6. InitAudioEffects(SampleRate)
│   ├── Reverb 初始化
│   ├── DRC 初始化
│   ├── EQ ×5 初始化
│   ├── Howling (啸叫抑制) 初始化
│   ├── Noise Suppressor 初始化
│   └── Expander 初始化
│
├── 7. InitControlGPIO()       # 控制 GPIO 初始化
├── 8. InitDetectionGPIO()     # 检测 GPIO 初始化
├── 9. A2dp_DecoderInit()      # SBC 解码器初始化
├── 10. BtStackServiceStart()  # 蓝牙协议栈启动
├── 11. ShellIOManager_Init()  # Shell IO 管理器
│
├── 12. Effect Graph 启动
│   ├── EffectGraph_Init()
│   ├── LoadPreset(DEFAULT)
│   ├── ChainGraph_AutoApplyOnStartup()
│   ├── EffectGraphVfs_TryAutoMount()
│   └── BG_AudioIO_SetupEffectGraphCallbacks()
│
└── 13. Shell 命令注册
    ├── ShellCmdGraph_Register()
    ├── ShellCmdSysmon_Register()
    ├── ShellCmdMetronome_Register()
    ├── ShellCmdMode_Register()
    └── ShellCmdFlash_Register()
```

### 6.4.4 主循环 (`Audio_loop`)

每一轮主循环（约 1-5ms 周期）：

```
Audio_loop()
│
├── 1. 蓝牙协议栈 Tick       # 处理蓝牙事件
│
├── 2. SetVolume()            # 恢复 ADC 电位器音量 (防 DSP 复位)
│
├── 3. USB 请求处理 + CDC 任务
│
├── 4. USB 热插拔检测
│
├── 5. 低功耗检测
│   ├── 5 个活动指标检查
│   │   ├── USB Audio 有数据?
│   │   ├── BT Audio 有数据?
│   │   ├── ADC 有信号?
│   │   ├── CDC 有通信?
│   │   └── BLE 有通信?
│   └── LowPower_Tick() → 空闲 5 分钟后 mute DAC
│
├── 6. 正常模式: AudioLoopWithGraph()
│   └── 执行 Effect Graph 拓扑中的每个节点
│
└── 7. ShellIOManager_Process()   # 处理 Shell 输入
```

### DAC 输出的门控机制

```c
static void DAC0_WriteSpeakerData(EffectNode_t *node, uint32_t *in_buf, uint16_t len) {
    // 提示音播放期间，放弃写入，避免冲突
    if (g_remind_sound_active)
        return;

    // 获取 DAC FIFO 剩余空间
    free_space = AudioDAC_DataSpaceLenGet(DAC0);

    // 限制单次写入量 ≤ 640 samples
    samples_to_write = (len < free_space) ? len : free_space;
    if (samples_to_write > 640) samples_to_write = 640;

    // 写入 DAC 硬件 FIFO
    if (samples_to_write > 0)
        AudioDAC_DataSet(DAC0, in_buf, samples_to_write);
}
```

## 6.6 低功耗管理

**文件**：`bg_low_power.h/.c`

### 工作流程

```
MainLoop → LowPower_Tick()
    │
    ├── 检查 5 个活动指标 (USB Audio/BT Audio/ADC Signal/CDC Comm/BLE Comm)
    │
    ├── 全部空闲 → 启动 5 分钟倒计时
    │   └── 超时 → 通知 Effect Graph mute DAC 输出
    │   └── 任一恢复 → 立即唤醒 DMA
    │
    └── 持续活跃 → 重置计时器
```

### 数据结构

```c
typedef struct {
    uint8_t  usb_audio_active;     // USB Audio 活跃
    uint8_t  bt_audio_active;      // BT Audio 活跃
    uint8_t  adc_signal_active;    // ADC 有信号输入
    uint8_t  cdc_comm_active;      // CDC 有通信
    uint8_t  ble_comm_active;      // BLE 有通信
    uint32_t idle_start_tick;      // 空闲起始时刻
    uint8_t  is_low_power;         // 当前是否低功耗
} LowPowerCtx_t;
```
