## 9.2 添加新功能指南

### 9.2.1 添加新的 Shell 命令

参照第 5 章的示例，步骤如下：

**步骤 1：创建命令模块文件**

在 `04_shell_commands/` 下创建 `shell_cmd_xxx.h` 和 `shell_cmd_xxx.c`

**步骤 2：实现命令处理函数**

```c
// shell_cmd_xxx.c
#include "bg_shell.h"

static int cmd_xxx_do_something(int argc, char *argv[]) {
    Shell_Printf("Running xxx command with %d args\r\n", argc);
    // 业务逻辑...
    return 0;
}

static const ShellOpt_t xxx_opts[] = {
    OPT("d", "do", "<arg>", "Do something", cmd_xxx_do_something),
    OPT_END()
};

DEFINE_MODULE(xxx, "My new command", MOD_CAT_DEBUG, xxx_opts);

void ShellCmdXxx_Register(void) {
    REGISTER_MODULE(xxx);
}
```

**步骤 3：注册模块**

在 `bg_shell_commands.c` 的 `Shell_RegisterAllModules()` 中添加：

```c
extern void ShellCmdXxx_Register(void);
ShellCmdXxx_Register();
```

### 9.2.2 添加新的 HAL 驱动

```c
// 01_hal_drivers/xxx/hal_xxx.h
#ifndef HAL_XXX_H
#define HAL_XXX_H

#include <stdint.h>

void HAL_XXX_Init(void);
void HAL_XXX_DoSomething(uint32_t param);

#endif
```

### 9.2.3 添加新的设备驱动

结合 VFS 驱动框架注册：

```c
// 03_driver_framework/drivers/drv_xxx.c
#include "drv_device.h"
#include "hal_xxx.h"

static int xxx_open(void *file) { ... }
static int xxx_read(void *file, void *buf, int len) { ... }
static int xxx_write(void *file, void *buf, int len) { ... }

DRV_DEVICE_DEF(xxx, "My Device", DRV_BUS_SPI, xxx_init);
DRV_PARAM_RO(xxx, "status", "%d", xxx_get_status);

void Xxx_DrvRegister(void) {
    DrvDevice_Register(&drv_xxx);
}
```

### 9.2.4 添加新的事件话题

在 `bg_event_topics.h` 中分配新的话题 ID：

```c
// 在空闲区域添加
#define EVT_MY_COMPONENT_READY      0x0100
#define EVT_MY_COMPONENT_ERROR      0x0101
```

发布事件：

```c
BG_EVT_PUB(EVT_MY_COMPONENT_READY);
```

订阅事件：

```c
static void on_my_event(uint16_t topic, void *data, uint16_t len) {
    // 处理...
}
BG_EVT_SUB(EVT_MY_COMPONENT_READY, on_my_event);
```

### 9.2.5 添加新的 Effect Graph 节点

在 `bg_audio_io_manager.c` 中添加新的回调并注册到 Effect Graph：

```c
// 1. 定义处理函数
static void MyEffect_Process(EffectNode_t *node, uint32_t *in_buf, uint16_t len) {
    // 音频处理逻辑
    for (int i = 0; i < len; i++) {
        // 修改 in_buf[i]
    }
}

// 2. 在 EffectGraph_Init() 中注册节点
EffectGraph_AddNode("my_effect", NODE_TYPE_EFFECT, MyEffect_Process);

// 3. 连接节点
EffectGraph_Connect("eq_output", "my_effect");
EffectGraph_Connect("my_effect", "mixer_input");
```

## 9.3 调试技巧

### 9.3.1 Shell 诊断命令

```bash
sys -i          # 系统信息一览
sys -f          # 堆内存剩余
sys -p          # 任务列表 (类似 Linux ps)
dbg -h          # 堆详细统计
battery         # 电池状态
graph -i        # Effect Graph 拓扑
```

### 9.3.2 串口诊断

通过 UART1 (115200 8N1) 输出，启动时观察诊断字符序列，定位启动失败位置。

### 9.3.3 GPIO 测试

```bash
gpio -w B 3 1   # 拉高 GPIO B3 (LED 亮)
gpio -r A 5     # 读取 GPIO A5 电平
```

### 9.3.4 音频调试

```bash
# 测试 DAC
audio -v 80                     # 设置音量 80%
remind -n                       # 播放提示音测试
pwr_music -p                   # 播放开机音乐测试

# 查看效果器
effect -l                       # 列出所有效果器
effect -g reverb               # 查看混响参数

# Looper 测试
looper -r 0                    # 开始录制段 0
looper -t 0                    # 停止录制
looper -p 0                    # 播放段 0
```

### 9.3.5 常见问题排查

| 症状 | 可能原因 | 排查方法 |
|------|----------|----------|
| 无法启动 | Flash 损坏/分区错误 | 重新烧录 Bootloader |
| 无声音 | DAC 静音/DMA 未启动 | `audio -i` 查看配置 |
| 噪音/爆音 | 采样率不匹配 | 检查 `SampleRate` 参数 |
| BLE 连不上 | 广播未开启 | `ble -a 1` 开启广播 |
| 堆不足 | 内存泄漏 | `sys -f` 定期检查 |
