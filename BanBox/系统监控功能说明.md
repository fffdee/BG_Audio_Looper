## 📝 新增的Shell命令

```bash
# 查看内存使用情况（剩余、已用、峰值）
sysmon -m
sysmon --memory

# 查看CPU占用率（每个任务的时间百分比）
sysmon -c
sysmon --cpu

# 查看任务信息（状态、优先级、栈使用）
sysmon -t
sysmon --tasks

# 查看系统信息（版本、时钟、配置）
sysmon -s
sysmon --sysinfo
```

## 🎯 主要用途

### 1. **性能调优**
找出哪个任务占用CPU最多，优化算法

### 2. **内存管理**
监控内存使用趋势，检测内存泄漏

### 3. **稳定性分析**
检查任务栈使用情况，预防栈溢出

### 4. **实时调试**
通过串口远程查看系统状态，无需重新编译

## 🔧 使用方法

### 通过CDC-UART访问
1. USB连接设备
2. 打开串口工具（115200波特率）
3. 输入命令，例如：`sysmon -m`

### 通过BLE访问
1. 蓝牙连接设备
2. 使用串口助手APP
3. 输入命令

## ⚙️ 技术细节

### FreeRTOS配置
工程已经配置好以下选项（位于 `FreeRTOSConfig.h`）：
```c
#define configUSE_TRACE_FACILITY                1  // 任务跟踪
#define configGENERATE_RUN_TIME_STATS           1  // CPU统计
#define configUSE_STATS_FORMATTING_FUNCTIONS    1  // 格式化输出(新增)
```

### 性能开销
- **代码空间**: 约2-3KB
- **RAM**: 仅在执行命令时临时分配2KB（执行完立即释放）
- **CPU**: 空闲时0%开销，执行命令时<5%

## 📖 典型应用场景

### 场景1: 调试音频失真
```bash
# 播放蓝牙音频时检查CPU占用
$ sysmon -c
# 如果AudioLoopTask占用>80%，说明音频处理负载过重
```

### 场景2: 检测内存泄漏
```bash
# 每隔5分钟执行一次
$ sysmon -m
# 如果"Minimum Ever Free"持续下降，说明有内存泄漏
```

### 场景3: 预防栈溢出
```bash
# 查看每个任务的剩余栈空间
$ sysmon -t
# 如果Stack值<100（即400字节），建议增加栈大小
```

## 🚀 快速测试

编译烧录后，在串口终端输入：

```bash
# 1. 查看帮助
help -m sysmon

# 2. 基础测试
sysmon -s  # 系统信息
sysmon -m  # 内存使用
sysmon -t  # 任务列表

# 3. CPU统计（需要运行一段时间才有数据）
sysmon -c
```

## ⚠️ 注意事项

1. **CPU统计精度**: 当前使用系统tick计数（1ms精度），对大多数应用已足够
2. **内存统计范围**: 只包含FreeRTOS堆内存，不包括栈和全局变量
3. **实时性**: 统计数据反映命令执行时刻的状态
