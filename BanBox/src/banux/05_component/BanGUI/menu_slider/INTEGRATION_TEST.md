/**
 * BG_MenuSlider 页面管理集成测试说明
 * 
 * 此文件说明了如何在项目中使用新集成的BG_MenuSlider控件页面
 */

## 使用方法

1. **编译项目**
   - 确保 bg_menu_slider.h 和 bg_menu_slider.c 文件已包含在编译配置中
   - 确保页面管理文件 page_manager.c 中的新代码正确编译

2. **运行演示**
   - 启动设备后，你会看到主菜单
   - 使用左/右键导航到 "BG Slider" 选项
   - 按确认键进入BG_MenuSlider演示页面

3. **演示页面功能**
   - **自动滑动**: 页面会自动在菜单项之间滑动
   - **手动控制**: 按左/右键可以手动控制滑动
   - **选择功能**: 按确认键选择当前菜单项
   - **返回主页**: 按退出键返回主菜单

4. **演示的菜单项**
   - Music: 音乐播放器演示
   - Games: 游戏中心演示  
   - Settings: 设置页面演示
   - Photo: 相册演示
   - Tools: 工具箱演示

## 技术特性展示

- **平滑动画**: 使用缓动函数实现平滑的滑动效果
- **自动滑动**: 3秒间隔自动切换菜单项
- **用户交互**: 支持手动控制，用户操作时自动停止自动滑动
- **状态管理**: 完整的页面生命周期管理
- **回调系统**: 每个菜单项都有独立的回调函数
- **视觉反馈**: 清晰的状态指示和操作提示

## 按键映射

| 按键 | 功能 |
|------|------|
| 左键 | 向左滑动菜单 |
| 右键 | 向右滑动菜单 |
| 确认键 | 选择当前菜单项 |
| 退出键 | 返回主菜单 |

## 代码架构

```
页面管理系统
├── home_page()           # 主菜单页面
├── list_page()           # 列表页面
├── list_page_in()        # 列表详情页面
└── bg_menu_slider_page() # BG_MenuSlider演示页面 ← 新增
    ├── 初始化控件
    ├── 处理用户输入
    ├── 更新动画状态
    ├── 绘制界面

```

## 集成要点

1. **页面ID管理**: 在 BG_Page_ID 枚举中添加了 BG_MENU_SLIDER_PAGE
2. **页面表配置**: 在 table 数组中添加了页面配置信息
3. **回调函数**: 实现了所有必要的回调函数
4. **状态管理**: 正确处理页面的初始化、运行和退出状态
5. **用户体验**: 提供清晰的操作提示和视觉反馈

这个集成演示了BG_MenuSlider控件在实际项目中的完整应用，包括与现有页面管理系统的无缝集成。
