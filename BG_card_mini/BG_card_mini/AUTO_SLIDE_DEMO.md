# 自动滑动菜单演示说明

## 功能说明

在main.c中添加了一个基于定时器的自动滑动菜单演示，每2秒自动切换一次菜单项。

## 关键特性

### 1. 自动定时滑动
- 每2秒（2000ms）自动向右滑动一次
- 基于Timer2的20ms中断实现精确计时
- 循环滑动，到最后一项后回到第一项

### 2. 菜单项配置
- 4个演示菜单项：Music、Set、Game、Photo
- 每个菜单项都有对应的回调函数
- 选中时会清屏并显示相应信息

### 3. 显示效果
- 红色边框：选中项
- 绿色边框：普通项
- 顶部显示当前项信息和演示状态
- 清除重叠避免图像干扰

## 代码结构

### 全局变量
```c
IconMenuSlider demo_slider;      // 菜单滑块对象
uint32_t auto_slide_timer = 0;   // 自动滑动计时器
uint8_t demo_mode_enabled = 0;   // 演示模式开关
uint8_t menu_demo_active = 0;    // 菜单演示是否激活
```

### 主要函数
1. `init_menu_demo()` - 初始化演示菜单
2. `update_menu_demo()` - 更新菜单显示
3. `Timer2Interrupt()` - 定时器中断，控制自动滑动
4. 菜单回调函数 - 处理菜单项选中事件

### 定时器逻辑
```c
// 每20ms调用一次
if (demo_mode_enabled && menu_demo_active) {
    auto_slide_timer++;
    if (auto_slide_timer >= 100) {  // 2000ms / 20ms = 100
        auto_slide_timer = 0;
        IconMenuSlider_Right(&demo_slider);  // 向右滑动
    }
}
```

## 使用方法

### 启动演示
演示会在系统启动时自动开始：
1. LCD初始化完成后自动启动
2. 显示"Auto Slide Demo"和"2s per slide"提示
3. 菜单开始自动滑动

### 手动控制
- 选中任意菜单项后，自动演示会停止
- 此时显示对应的选中信息
- 可以通过重启系统重新开始演示

## 技术要点

### 1. 定时精度
- 使用Timer2的20ms精确中断
- 计数100次达到2秒精度
- 避免了系统延时函数的不准确性

### 2. 显示优化
- 使用`BG_lcd.Box()`清除特定区域
- 避免全屏清除造成的闪烁
- 分离演示模式和正常页面系统

### 3. 内存管理
- 菜单项使用静态字符串，节省内存
- 不使用图标数据，减少内存占用
- 简化的图形绘制，提高性能

## 故障排除

### 1. 菜单不显示
- 检查`demo_mode_enabled`和`menu_demo_active`状态
- 确认Timer2中断正常工作
- 验证LCD初始化完成

### 2. 滑动不流畅
- 检查主循环调用频率
- 确认`IconMenuSlider_Update()`正常调用
- 验证帧缓冲模式设置

### 3. 显示重叠
- 确认清除区域范围正确
- 检查页面系统是否冲突
- 验证显示区域边界

## 性能数据

- **滑动周期**: 2秒精确
- **动画帧率**: 约50-60 FPS（取决于主循环）
- **内存占用**: < 1KB（主要是菜单结构体）
- **CPU占用**: < 5%（主要在定时器中断和绘制）
